# DisplayToggle

**English** | [Русский](#displaytoggle--русский)

A tiny macOS menu bar app that turns individual displays **off and back on in software** — as if you pulled the cable, without touching it.

Built for a common setup: one of your monitors is shared with another computer or console (a KVM, a second input, a "hybrid" monitor). macOS still sees it as connected, so new windows keep opening on a screen you aren't looking at. With DisplayToggle you switch that monitor off for the Mac in one click or one shortcut, and bring it back just as fast.

## Features

- **Menu bar only** — no Dock icon. Every connected display is listed; a checkmark means it's on. Click to toggle.
- **Global keyboard shortcuts** — work from any app, no Accessibility permission needed:
  - `⌃⌥⌘0` — enable all displays
  - `⌃⌥⌘1`, `⌃⌥⌘2`, … — toggle each display (assigned automatically as displays are first seen)
  - Fully configurable in **Keyboard Shortcuts…**: click a field, press a combo; `Esc` cancels, `⌫` clears. If macOS reports the combo as already taken, it is rejected with a message.
  - Shortcuts are bound to the display itself (vendor/model/serial), so they survive reconnects.
- **Safe by design**
  - The last active display can never be turned off.
  - Changes are **session-only**: logging out or rebooting always brings every display back.
  - **Quit** re-enables all displays first.
- **Launch at Login** toggle (via `SMAppService`).
- Russian and English UI, follows the system language.
- Universal binary (Apple Silicon + Intel), macOS 13+.

## Install

Download `DisplayToggle-X.Y.Z.dmg` from [Releases](../../releases), open it and drag **DisplayToggle** to **Applications**.

The app is not notarized (no Apple Developer account). On first launch macOS will block it: open **System Settings → Privacy & Security** and click **Open Anyway** — or run:

```bash
xattr -dr com.apple.quarantine /Applications/DisplayToggle.app
```

## Build from source

Requires Xcode 15+ (or the Command Line Tools with Swift 5.9+).

```bash
git clone https://github.com/ArturRuZ/DisplayToggle.git && cd DisplayToggle
swift test                                # unit tests
scripts/build_app.sh 1.1.0 --install      # dist/DisplayToggle.app → ~/Applications, then launch
scripts/build_dmg.sh 1.1.0                # dist/DisplayToggle-1.1.0.dmg (optional: brew install fileicon)
```

The icon is generated by `swift scripts/make_icon.swift assets/AppIcon.icns`.

A release is cut by pushing an annotated tag (`git tag -a v1.2.0 -m "…" && git push origin v1.2.0`): GitHub Actions runs the tests, builds the `.app` and `.dmg` on a macOS runner and publishes it; the tag message becomes the release notes. Every push to `main` and every PR runs the tests and a trial build (`.github/workflows/ci.yml`).

## How it works

Turning a display off uses the private CoreGraphics call `CGSConfigureDisplayEnabled` (the same mechanism tools like BetterDisplay use for "disconnect"), committed with `CGCompleteDisplayConfiguration(…, .forSession)`. Being private, it may change in a future macOS — if toggling stops working, the app just beeps. Global shortcuts use Carbon `RegisterEventHotKey`.

# DisplayToggle — Русский

[English](#displaytoggle) | **Русский**

Маленькое приложение для строки меню macOS: **программно отключает и включает** отдельные мониторы — как будто выдернул кабель, только не трогая его.

Сделано под частую ситуацию: один из мониторов делится с другим компьютером или приставкой (KVM, второй вход, «гибридный» монитор). macOS продолжает считать его подключённым, и новые окна открываются на экране, на который ты сейчас не смотришь. DisplayToggle отключает такой монитор для мака одним кликом или сочетанием клавиш — и так же быстро возвращает.

## Возможности

- **Только строка меню**, без значка в Dock. В меню все мониторы; галочка — включён. Клик — переключить.
- **Глобальные горячие клавиши** — работают из любой программы, разрешение «Универсальный доступ» не нужно:
  - `⌃⌥⌘0` — включить все мониторы
  - `⌃⌥⌘1`, `⌃⌥⌘2`, … — вкл/выкл каждый монитор (назначаются автоматически при первом появлении монитора)
  - Настраиваются в **Горячие клавиши…**: нажми на поле и введи сочетание; `Esc` — отмена, `⌫` — очистить. Если macOS сообщит, что сочетание уже занято, оно не примется — будет сообщение.
  - Клавиши привязаны к самому монитору (производитель/модель/серийник), поэтому переживают переподключение.
- **Безопасность**
  - Последний работающий монитор отключить нельзя.
  - Изменения действуют **до конца сеанса**: выход из учётной записи или перезагрузка всегда возвращают все мониторы.
  - **Выход** из программы сначала включает все мониторы.
- Переключатель **«Запускать при входе»** (через `SMAppService`).
- Интерфейс на русском и английском, по языку системы.
- Универсальная сборка (Apple Silicon + Intel), macOS 13+.

## Установка

Скачай `DisplayToggle-X.Y.Z.dmg` из [Releases](../../releases), открой и перетащи **DisplayToggle** в **Программы**.

Приложение не нотаризовано (нет аккаунта Apple Developer). При первом запуске macOS его заблокирует: открой **Системные настройки → Конфиденциальность и безопасность** и нажми **Всё равно открыть** — или выполни:

```bash
xattr -dr com.apple.quarantine /Applications/DisplayToggle.app
```

## Как это работает

Отключение монитора — приватный вызов CoreGraphics `CGSConfigureDisplayEnabled` (тот же механизм, что «disconnect» в BetterDisplay), применяется через `CGCompleteDisplayConfiguration(…, .forSession)`. API приватный и может измениться в будущих macOS — если переключение перестанет работать, приложение просто издаст звуковой сигнал. Горячие клавиши — Carbon `RegisterEventHotKey`.
